# Claude Auto-Approve

Claude Code를 여러 터미널 세션에서 돌릴 때 사람이 자리를 비우면 작업이 멈추는 두 가지 상황을 자동으로 처리하는 macOS용 도구입니다.

1. **권한 확인 대기** — "Do you want to proceed?" 같은 승인 다이얼로그가 뜨면 자동으로 승인합니다.
2. **사용 한도 도달** — 한도 문구와 리셋 시각을 읽어, 리셋 후 해당 세션에만 재개 명령을 보냅니다.

그 밖에 터미널 내용이 30분 동안 변하지 않으면 멈춘 것으로 보고 재개 명령을 보내며, 선택적으로 작업 중인 git 저장소를 커밋합니다.

## 동작 방식

- iTerm2와 cmux 세션의 화면 텍스트를 AppleScript / cmux CLI로 2초마다 읽습니다.
- 다이얼로그·한도 문구는 패턴으로 판별하고, 한도 판정은 오탐을 줄이려고 두 개 이상의 패턴이 겹칠 때만 인정합니다.
- 같은 다이얼로그에 입력이 반복되지 않도록 세션별 처리 상태와 쿨다운을 둡니다.
- 상태와 설정은 로컬 웹 대시보드(`http://localhost:17654`)에서 확인·변경합니다.

## 실행

```bash
bash setup.sh   # Pillow 설치 확인
bash run.sh     # 또는 python3 app.py
```

macOS 권한 두 가지가 필요합니다: 시스템 설정 → 개인정보 보호 및 보안 → **화면 기록**, **손쉬운 사용**에서 터미널 앱 허용.

## 파일

| 파일 | 역할 |
|---|---|
| `app.py` | 세션 감지·자동 승인·한도 재개·멈춤 감지 + 웹 대시보드 (현재 버전) |
| `claude_auto_approve.py` | 초기 버전 (화면 영역 OCR + tkinter UI) |
| `run.sh`, `ensure_running.sh` | 실행 / 꺼져 있으면 다시 띄우기 |
| `create_app.sh`, `make_icon.py` | macOS 앱 번들과 아이콘 생성 |
